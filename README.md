# Moveo — AI Crypto Advisor

A personalized crypto investor dashboard. After a short onboarding quiz, users get a
daily dashboard with market news, coin prices, an AI insight of the day, and a meme —
tailored to their preferences. Thumbs up/down feedback on each section is stored for
future recommendation improvements.

## Tech stack
- **Frontend:** React + Vite + TypeScript
- **Backend:** NestJS (REST API)
- **Database:** MongoDB (Mongoose)
- **Auth:** JWT

## Structure
- `backend/`  — NestJS API (auth, users, dashboard, votes)
- `frontend/` — React single-page app
